🔄 쟈쟈 데이터 갱신기

공홈이 프로그램 접근을 막아서, 공홈을 연 브라우저가 대신 데이터를 받아 깃허브에 올리는 방식이에요. 사이트랑 디코 봇은 깃허브에 올라간 데이터를 알아서 가져가요.

① 처음 한 번만 — 버튼 만들기
  1. 아래 노란 버튼을 즐겨찾기 바로 드래그해서 놓기 (즐겨찾기 바가 안 보이면 Ctrl+Shift+B)
  2. 깃허브 토큰 만들기: github.com → 프로필 → Settings → Developer settings → Fine-grained tokens → Generate new token
    · Repository access: Only select repositories → llumixxx/jaja
    · Permissions → Repository permissions → Contents: Read and write
    · 만들어진 토큰(github_pat_…) 복사해두기

🔄 쟈쟈 갱신

② 갱신할 때마다
  1. 공홈 정보 페이지 열기
  2. 즐겨찾기의 🔄 쟈쟈 갱신 클릭 → 오른쪽 위에 창이 떠요
  3. 처음이면 토큰 붙여넣기 (그 브라우저에 저장돼서 다음부턴 안 물어봐요)
  4. 원하는 항목 체크 → 갱신 시작

· 펫·아이템·새 펫 이미지는 몇 초면 끝나요 · 랭킹은 서버 부담 없게 천천히 받아서 3~5분
· 바뀐 게 있을 때만 깃허브에 저장해요
