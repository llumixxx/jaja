✨ 기능
이름·단축키 자유 변경 — 목록에서 이름을 고치고, 단축키 버튼을 눌러 원하는 키 조합으로 바꿀 수 있어요. 추가·삭제도 가능.
게임 창에서만 작동 — 다른 창에서는 Ctrl+1 같은 키가 원래대로 동작해요.
Ctrl 누른 채 연속 입력 — Ctrl을 누른 채 1, 1, 1 누르면 연속으로 들어가요.
클립보드 보존 — 원래 복사해둔 글자는 입력 후 자동으로 되돌려 놔요.
트레이 실행 · 자동 시작 — 창을 닫아도 트레이에서 계속 돌고, 윈도우 시작 시 자동 실행도 켤 수 있어요.

백신이 바이러스라고 지워버렸어요
단축키 감지·키 입력·클립보드 사용 같은 기능 때문에 생기는 오탐이에요. 윈도우 보안 → 바이러스 및 위협 방지 → 보호 기록에서 해당 항목 허용을 눌러주세요. 걱정되면 위의 소스코드(pet_name_helper.py)를 직접 확인해 보셔도 됩니다.
디스코드에 파일로 올리면 막혀요
같은 오탐 이유예요. 파일 대신 이 페이지 링크를 공유해주세요.
